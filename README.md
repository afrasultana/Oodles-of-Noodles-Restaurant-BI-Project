# 🍜 Oodles of Noodles - Restaurant Business Dashboard (Power BI)

This project uses Power BI to analyze the performance of a fictional meal kit delivery service. It explores revenue, regional performance, subscription types, cuisine preferences, and customer satisfaction trends.

## 🔍 Key Insights
- 📈 **Revenue** exceeded the projected goal by 12.84% in the most recent month.
- 🌍 **Middle Atlantic** is the top-performing region by revenue.
- 🍱 **Japanese Cuisine** is the most popular in terms of meal kit orders.
- 🔁 Most subscribed plan: **3 meal kits with 2 servings**.
- ⏱️ **SLA compliance** at 99.9%, far above the 90% target.

---

## 🛠️ Tools Used
- Power BI Desktop
- DAX for calculations and KPIs
- Drillthrough filters and dynamic slicers
- Custom visuals (gauge, donut, tree map)
